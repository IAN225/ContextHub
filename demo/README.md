# Context Hub · 对话手账 Demo

本地对话手账：原文、Note 与记忆包可以实际编辑保存，三种导入与模型摘要已接入实际处理流程；远程记忆连接仍为演示。入口是手账书架，每个工作区以一本对话册呈现。

## 运行

已启动的预览：<http://127.0.0.1:3000/>。

在 `demo` 目录运行：

```powershell
pnpm build
pnpm db:init
pnpm start
```

也可运行 `start-demo.ps1`，默认构建、应用队列迁移、启动完整本地服务；`start-demo.ps1 -Dev` 或 `pnpm dev` 用于开发。启动前先结束占用 3000 的旧服务。依赖已安装；新环境使用 pnpm 与已提交的锁文件安装。项目未注册或部署云端 Site。导入的完整说明、网络限制和模块入口见 [对话导入说明](../docs/conversation-imports.md)。

## 可以实际操作

- 本地数据：首次使用为空书架，既有数据保留；顶部“本地数据”支持 JSON 全量备份、覆盖前备份下载和事务恢复。回收站满 30 天时在应用打开、聚焦及每小时清理，也可确认后手动清空。范围与恢复规则见 [本地数据说明](../docs/2026-09-10-local-data.md)。
- 手账书架：选择工作区、创建工作区、修改工作区名称、章节过渡、返回书架。手机与桌面封面比例一致；点击后先浮起 380ms，同时预挂载原文页再进入。Escape 可取消，减少动态效果模式直接进入。
- 原文：固定中心刻度，滚动、触屏与键盘导航；搜索及跳转；超过 400 个结果时只渲染视口和目标附近的刻度，保留完整滚动宽度；桌面滚轮逐轮平滑居中，触屏支持惯性、截停和结束吸附。查看预览、Payload、元数据。正常、弃用与回收站按完整 user 轮次维护。
- 编辑：在任意轮次前后插入，保留已有工具消息顺序；Markdown 文本编辑与安全预览；图片粘贴、附件添加（单个 5 MB），浏览器 IndexedDB 保存素材与草稿。对话/Note 编辑器关闭或切换后可恢复草稿，点击遮罩不关闭。
- 摘要：连接本地配置的真实模型，按完整轮次和预算增量压缩；支持手动启动、逐批检查、托管、暂停和最多 30 个检查点。完整结果成功保存才推进水位；失败暂停，过期结果不覆盖。初次启用会关闭旧演示自动配置。任务由本地服务执行，离开章节或关闭网页仍可继续。配置见 [摘要压缩说明](../docs/summary-compression.md)。
- 后台任务：首页与手账顶部查看摘要、工作台和附件任务，支持本批后暂停、继续、取消及重试接收。任务与结果在本机队列持久化，服务需保持运行。详见 [附件与后台任务](../docs/2026-09-10-attachments-background.md)。
- 工作台：选择任意历史摘要与完整原文范围，调用模型生成候选摘要后单独预览确认；未确认候选保留在对应手账的工作台，应用时再次选择水位策略。
- Note：编辑与保存版本、标星、弃用、回收站、恢复，最多 5 个历史版本。工具栏使用透明、无外框的紧凑双按钮，中间竖线分隔；左侧笔形按钮新建，右侧放大镜向左展开搜索并自动聚焦；点击外部或按 Escape 清空搜索并收起。
- 记忆包：动态引用、可编辑文本块、拖拽与上下移动排序、预览及复制。默认返回活跃摘要、原文窗口、标星 Note 的 id/标题；正文单独读取。
- 收件箱：统一接收分享链接导入与第三方客户端投递的上下文。可重命名、预览、删除所选完整轮次、删除整份收件、拼接到已有手账或新建手账。像素小猫统计两种来源的待归档内容，可用鼠标或触屏自由拖动并记住位置，点击打开收件箱；有待归档上下文时切换为抱信状态。聚焦后也可用方向键移动。
- 手动复制：解析带角色标记的文本或请求 JSON，保留代码块并预览完整轮次。无法识别角色时明确按一条用户原文处理；旧请求 JSON 草稿可继续编辑。
- 分享链接：读取成功后直接进入收件箱，稍后可查看原文和归档；旧的未确认链接也出现在收件箱。来源受限或失效时明确报错。手动复制保留独立确认窗口。
- 客户端投递：真实本地 HTTP 接口接收 Chat Completions / Responses / Anthropic Messages 上下文，返回 JSON/SSE 收件回执。支持生成、轮换和吊销真实 Key，队列持久化、会话隔离与重试去重。浏览器成功保存后才确认接收；工具结果留在发起 user 的轮次内，隐藏思考结构块不保存。
- 搜索：跨手账按关键词搜索正常原文、摘要、正常 Note；原文结果展开完整轮次。无向量搜索或外部调用。
- 连接：模拟 OAuth 授权范围确认、独立工作区演示令牌的创建/过期/重新生成/吊销。

## 明确的演示边界

- 不存在云端账号、OAuth 或远程 MCP。连接页的记忆令牌仍为演示；客户端投递使用单独的真实本地 Key 和 HTTP 接口。
- 用户已自行确认分享导入、手机体验和另一设备模型正常返回。来源仍可能因站点限制返回 403/超时；原有分享链接和原始样本只留在被忽略的本地文件中。
- 摘要已实现四协议适配、保守输入预算、实际请求探测与持久化后台队列。本机 DeepSeek Responses 小请求探测的思考 token 为 0；换设备需自行填写 `.env.summary.local`，压缩质量仍待验收。后台服务中断的模型请求暂停待检查，不自动重试。字段被接受不证明最大上限。
- 请求 JSON 的内嵌附件保留字节，公开 HTTPS 引用后台获取；缺失来源/平台私有 ID/失败下载明确显示状态。纯文本附件可供摘要读取，图片、PDF 等仅保存文件，不做内容识别。
- 页面关闭时不执行回收站清理，下次打开补做。删除时间缺失或无效的旧记录不会自动删除，可手动清空；恢复备份后回收站再保留 30 天。
- Markdown 预览支持标题、粗体、列表及代码块，使用 React 文本节点渲染，未经完整 CommonMark 实现；不执行原文 HTML。当前编辑器是 Markdown 文本编辑器与预览，非完整所见即所得编辑器。
- 手账、草稿和已接收候选在当前 origin 的 IndexedDB；未接收的客户端投递在本机 `.wrangler/state` 队列。接收成功后队列清除正文，只留去重凭证。清除浏览器站点数据会丢失本地手账，换浏览器/端口不共享；没有跨设备同步。
- 支持实验性 `document.modelContext` 的浏览器可注册两个只读本地预览工具。普通浏览器自动跳过；未在支持此实验 API 的浏览器内验证注册行为。它们不等同于用户需求里的远程 MCP 服务。

## 建议评审顺序

1. 从空书架新建手账，或通过收录入口导入自己的对话并归档，浏览时间轴与完整轮次。
2. 配置本地模型后进行摘要压缩，积累检查点，再试“保留进度”观察原文覆盖与缺口。
3. 选择历史检查点并“跟随回退”，查看窗口与水位变化，再逐批继续压缩。
4. 新建一条标星 Note，到记忆包查看 id 列表随之变化，并尝试拖动编排块。
5. 在收录入口手动粘贴文本/JSON 并预览归档；在客户端投递页配置真实接口，测试收件箱接收。
6. 关闭编辑器、切换章节、刷新页面，验证草稿仍在。
7. 在独立测试环境导出备份、修改数据并恢复，检查原文、Note 版本与附件；验证回收站恢复和清空。
