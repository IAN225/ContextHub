# Context Hub · 对话手账 Demo

本阶段交付可交互的本地前端原型，供评审产品逻辑。入口是手账书架，每个工作区以一本对话册呈现，翻开后通过书签切换原文、摘要、Note、记忆包与连接。

## 运行

已启动的预览：<http://127.0.0.1:3000/>。

在 `demo` 目录运行：

```powershell
node node_modules/vinext/dist/cli.js dev --hostname 127.0.0.1 --port 3000
```

也可运行 `start-demo.ps1`。依赖已安装；在新环境安装时使用 pnpm 与已提交的 `pnpm-lock.yaml`。项目基于 Sites 提供的 Vinext / React / TypeScript / Shadcn Base UI 脚手架，未注册或部署云端 Site。

## 可以实际操作

- 手账书架：选择工作区、创建工作区、修改工作区名称、章节过渡、返回书架。手机与桌面封面比例一致；点击后先浮起 380ms，同时预挂载原文页再进入。Escape 可取消，减少动态效果模式直接进入。
- 原文：固定中心刻度，滚动、触屏与键盘导航；搜索及跳转；原生轨道当前渲染全部时间节点；桌面滚轮逐轮平滑居中，连续输入从目标轮次推进，触屏支持惯性、截停和结束吸附。查看预览、Payload、元数据。正常、弃用与回收站按完整 user 轮次维护。
- 编辑：在任意轮次前后插入，保留已有工具消息顺序；Markdown 文本编辑与安全预览；图片粘贴、附件添加（单个 5 MB），浏览器 IndexedDB 保存素材与草稿。对话/Note 编辑器关闭或切换后可恢复草稿，点击遮罩不关闭。
- 摘要：示例增量摘录、手动启动、逐批检查、托管、暂停、最多 30 个检查点。窗口跟随处理水位移动。回退可重置水位或保留进度；缺口可见，缺口内容不进入默认记忆包。首次完成后可开启后续自动演示。模拟压缩不依赖服务器；章节保持挂载后的隐藏页任务生命周期仍需进一步审查。
- 工作台：选择任意历史摘要与完整原文范围，模拟生成候选摘要后进入收件箱；应用候选时再次选择水位策略。
- Note：编辑与保存版本、标星、弃用、回收站、恢复，最多 5 个历史版本。
- 记忆包：动态引用、可编辑文本块、拖拽与上下移动排序、预览及复制。默认返回活跃摘要、原文窗口、标星 Note 的 id/标题；正文单独读取。
- 收件箱：重命名、全文预览、删除所选完整轮次、删除上传、拼接到已有工作区或新建工作区。
- 投递请求：本地粘贴 JSON，解析 Chat Completions / Responses / Anthropic Messages 的主要消息结构。工具结果不会生成伪用户轮次；隐藏思考结构块不保存。
- 搜索：跨手账按关键词搜索正常原文、摘要、正常 Note；原文结果展开完整轮次。无向量搜索或外部调用。
- 连接：模拟 OAuth 授权范围确认、独立工作区演示令牌的创建/过期/重新生成/吊销。

## 明确的演示边界

- 不存在真实账号系统、云端数据隔离、OAuth 服务、访问令牌校验或远程 MCP/API 服务。所有地址使用不可连接的 `.invalid` 域名，令牌带 `demo_` 前缀。
- 分享链接按钮只创建解析结果**示例**，不读取链接实际内容。根目录用户的 `share_url.txt` 和既有观察记录保持原样，没有把私人样本内容写入 demo。
- 摘要由确定性的原文摘录模拟，未请求任何模型。提示词、输入预算、思考和字段配置用于评审；尚无模型 token 预算计算、真实能力探测、服务器锁、后台调度、网络失败重试。三态能力记录清楚标注为示例。
- 请求 JSON 内的图片/附件引用只留下缺失说明，不下载素材。手动添加的文件才实际保存字节。
- 回收站显示删除时间，30 天清理须由未来的后台实现；本地 demo 不自动清除。
- Markdown 预览支持标题、粗体、列表及代码块，使用 React 文本节点渲染，未经完整 CommonMark 实现；不执行原文 HTML。当前编辑器是 Markdown 文本编辑器与预览，非完整所见即所得编辑器。
- 数据与草稿仅存在于当前浏览器、当前 origin 的 IndexedDB；清除浏览器站点数据会丢失，换浏览器/端口不共享。不要把原型当作唯一的长期备份。
- 支持实验性 `document.modelContext` 的浏览器可注册两个只读本地预览工具。普通浏览器自动跳过；未在支持此实验 API 的浏览器内验证注册行为。它们不等同于用户需求里的远程 MCP 服务。

## 建议评审顺序

1. 从书架翻开“慢慢聊，慢慢来”，浏览时间轴与完整轮次。
2. 在摘要页选“第一次整理”，先试“保留进度”，查看 156–200 轮形成的缺口。
3. 再选该检查点并“跟随回退”，查看窗口移动到早期，逐批继续模拟压缩。
4. 新建一条标星 Note，到记忆包查看 id 列表随之变化，并尝试拖动编排块。
5. 在收录入口粘贴请求 JSON，进入收件箱删除一轮后归档。
6. 关闭编辑器、切换章节、刷新页面，验证草稿仍在。
