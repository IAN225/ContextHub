# 桌宠角色包

在 **设置 → 偏好 → 桌宠** 下载模板、上传 ZIP 并预览三个状态。点击“启用”后保存到当前账号，其他设备登录同一账号即可使用。“恢复默认”切换回内置邮差小猫，同时保留已保存的自定义包，可再次启用。上传失败不会替换当前桌宠。

目前每个账号保留一个自定义角色包。图片和选择随账号保存在服务器，纳入个人 JSON 备份和完整实例备份；浏览器只保留播放缓存。本功能不需要新增数据库迁移。

## 格式

支持 ContextHub 目录帧 v1 和 Codex 图集 v1/v2。上传时自动识别格式；设置页分别提供两种模板。下面先介绍目录帧。

```text
my-cat.zip
├─ pet.json
├─ idle/001.png
├─ idle/002.png
├─ drag/001.png
└─ mail/001.png
```

```json
{
  "schemaVersion": 1,
  "name": "邮差小猫",
  "animations": {
    "idle": { "directory": "idle", "fps": 6, "loop": true },
    "drag": { "directory": "drag", "fps": 10, "loop": true },
    "mail": { "directory": "mail", "fps": 8, "loop": true }
  }
}
```

ZIP 可直接包含这些文件，也可以套一层文件夹；只能有一个 pet.json。directory 相对于 pet.json，帧文件放在该目录的直接下级，按文件名中的数字顺序播放，建议命名为 001.png、002.png。透明背景、统一画布尺寸的图片效果更稳定。

| 字段          | 要求                                   |
| ------------- | -------------------------------------- |
| schemaVersion | 固定为 1                               |
| name          | 1–60 字                                |
| idle          | 必需，至少一帧                         |
| drag / mail   | 可选，缺少配置或目录为空时使用 idle    |
| directory     | 包内相对目录，不允许绝对路径或上级路径 |
| fps           | 1–30，每秒帧数                         |
| loop          | true 循环；false 播放一次并停在末帧    |

支持静态 PNG、WebP，不支持 GIF、动画 WebP/APNG、SVG 或外部图片地址。单帧最大 512 × 512、2 MB；合计最多 240 帧、约 838 万像素。ZIP 最大 12 MB、256 个条目，解压后合计最大 16 MB。ZIP 不支持加密、分卷、ZIP64 或符号链接。

## 播放与交互

按住或拖动优先播放 drag；松手后有待处理收件则播放 mail，否则播放 idle。缺少某状态时使用 idle，一张图片也可使用。模板三个状态均循环播放。后台标签页暂停播放；系统启用“减少动态效果”时显示首帧。

拖动位置、点击打开收件箱、未读角标和收件轮询沿用原有交互。上传解压及图片解码在浏览器后台线程进行，有尺寸和时间限制；文件校验成功后才提供启用操作。

## Codex 图集兼容

将 Codex 自定义桌宠目录中的 pet.json 和图片一起压成 ZIP，即可上传。支持配置默认值：省略 spriteVersionNumber 时按 v1，省略 spritesheetPath 时读取 spritesheet.webp；名称依次取 displayName、id、外层目录名。名称最多保存 60 字。

```json
{
  "displayName": "邮差小猫",
  "spriteVersionNumber": 2,
  "spritesheetPath": "spritesheet.png"
}
```

图集单格为 192 × 208，8 列。v1 为 1536 × 1872（9 行），v2 为 1536 × 2288（11 行）。PNG/WebP 图集最大 20 MB，ZIP 最大 24 MB；不支持远程 URL、加密 ZIP 或未知版本。目录帧原有大小限制保持不变。

| ContextHub 状态 | Codex 动画（从 0 开始的行号） | 帧数 |
| --------------- | ----------------------------- | ---- |
| 默认            | idle，第 0 行                 | 6    |
| 按住 / 拖动     | running，第 7 行              | 6    |
| 待处理收件      | waving，第 3 行               | 4    |

保留这些帧的原始时长，并按 ContextHub 的收件状态持续循环。v2 额外的视线跟随帧没有对应交互。导入兼容指素材格式和选用动画兼容，不复刻 Codex 的整套交互。

浏览器在 Worker 中解码图集、拆出所需的 16 帧，保存成账号已有的帧格式；帧时长和来源标记随备份保存。服务器不用安装图像处理依赖。Codex 模板使用本项目原创小猫图像，可把同一份模板解压到 Codex 自定义桌宠目录使用；它没有包含 Codex 内置角色素材。

格式及布局核对来源：本机 Codex desktop 26.908.9136.0 安装包中的角色包校验器和播放器元数据。将来 Codex 新增图集版本时，需要明确增加适配；不会猜测未知布局。
