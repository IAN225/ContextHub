# 制作自己的桌宠

在 **设置 → 偏好 → 桌宠** 下载 **Codex 模板**。解压后，修改名称和图集，再压成 ZIP 上传；预览三个状态，点击“启用”即可保存到账号。其他设备登录同一账号也会使用该桌宠。

## 从模板开始

1. 解压模板，保留 `pet.json` 和 `spritesheet.png`。
2. 用支持透明图层的绘图软件打开图集，例如 Krita、GIMP 或 Photoshop。保持画布 **1536 × 2288 像素**，设置网格为 **192 × 208 像素**，从左上角开始排列。
3. 将模板中的小猫替换成你的角色。每格是一帧，使用透明背景，保持角色在各帧中的大小和脚底位置一致，避免播放时跳动。不要把参考网格线导出到图片中。
4. 按下表绘制三个状态。行、列在本说明中都**从 1 开始计数**，从左往右播放。只做静态角色时，把同一张图重复放入这些格子；所需格子不能完全透明。其余行可以先保留模板内容。
5. 编辑 `pet.json` 的 `displayName`，使用 UTF-8 保存。如果改成 WebP，也要把 `spritesheetPath` 改成对应文件名。
6. 选中 `pet.json` 和图集文件，压缩为 ZIP；也可以将包含这两个文件的文件夹压缩。上传后检查默认、拖动、收件预览，再启用。

| 状态        | 图集位置           | 播放帧数 | 每帧时长（毫秒，从左往右）     |
| ----------- | ------------------ | -------- | ------------------------------ |
| 默认        | 第 1 行，第 1–6 列 | 6        | 1680、660、660、840、840、1920 |
| 按住 / 拖动 | 第 8 行，第 1–6 列 | 6        | 120、120、120、120、120、220   |
| 待处理收件  | 第 4 行，第 1–4 列 | 4        | 140、140、140、280             |

例如，收件动画的第一帧左上角在 **x = 0、y = 624**，占用 192 × 208 像素；第二帧从 x = 192 开始。每行共有 8 格，表中未使用的列不会参与 ContextHub 播放。

按住或拖动时优先播放拖动动画；松手后有待处理收件则播放收件动画，否则播放默认动画。三个状态均循环播放，时长由图集版本决定，不能通过 `fps` 字段更改。后台标签页暂停动画；启用系统“减少动态效果”时显示首帧。

## 包内文件和配置

```text
my-cat.zip
├─ pet.json
└─ spritesheet.png
```

```json
{
  "id": "my-cat",
  "displayName": "我的小猫",
  "spriteVersionNumber": 2,
  "spritesheetPath": "spritesheet.png"
}
```

| 字段                | 填写方法                                                  |
| ------------------- | --------------------------------------------------------- |
| id                  | 角色标识，建议使用英文字母、数字和连字符，例如 my-cat     |
| displayName         | 显示名称，建议 1–60 字；省略时使用 id 或外层文件夹名      |
| spriteVersionNumber | 模板使用 2；也支持 1，省略时按 1 读取                     |
| spritesheetPath     | 相对于 pet.json 的包内图片路径；省略时为 spritesheet.webp |

PNG 和 WebP 都必须是静态图集。v1 为 **1536 × 1872（8 列、9 行）**；v2 为 **1536 × 2288（8 列、11 行）**。两个版本使用相同的三个动画位置。图集最大 **20 MB**，ZIP 和解压后总量最大 **24 MB**，最多 256 个条目。只能有一个 pet.json。不支持外部图片 URL、SVG、GIF、APNG、动画 WebP、加密 ZIP、ZIP64 或符号链接。

## 使用已有 Codex 桌宠

将已有 Codex 自定义桌宠中的 pet.json 和对应图集一起压缩为 ZIP，再上传即可。模板使用 ContextHub 原创小猫，可以在支持该格式的 Codex 中使用；若要重新绘制后也用于 Codex，请保留或补齐其他动画行，因为 Codex 会使用更多状态。ContextHub 只使用上表中的动画，不提供 Codex 的其他角色交互。

本格式根据 Codex desktop 26.908.9136.0 的本机包校验器和播放器元数据核对，支持图集 v1/v2；新版本布局需要另行适配。

## 保存与恢复

每个账号保存一个自定义桌宠，启用新包会替换已保存的自定义包。“恢复默认”切换回内置邮差小猫，保留当前自定义包，之后可以再次启用。拖动位置、收件轮询、点击打开收件箱和未读角标继续沿用。

图片、名称、帧时长和选择随账号保存，纳入个人 JSON 导出和实例备份。已经保存的旧桌宠仍然可用；新上传统一使用 Codex 图集。上传时浏览器在后台线程解码图集，将所需帧保存为账号素材，服务器无需安装图像处理工具。
