# 桌宠角色包

在 **设置 → 偏好 → 桌宠** 下载模板、上传 ZIP 并预览三个状态。点击“启用”后保存到当前账号，其他设备登录同一账号即可使用。“恢复默认”切换回内置邮差小猫，同时保留已保存的自定义包，可再次启用。上传失败不会替换当前桌宠。

目前每个账号保留一个自定义角色包。图片和选择随账号保存在服务器，纳入个人 JSON 备份和完整实例备份；浏览器只保留播放缓存。本功能不需要新增数据库迁移。

## 格式

使用 ContextHub 角色包格式 v1；不是 Codex spritesheet 格式，两者不能直接互换。

```text
my-cat.zip
├─ pet.json
├─ idle/001.png
├─ idle/002.png
├─ drag/001.png
└─ mail/001.png
```

```json
{
  "schemaVersion": 1,
  "name": "邮差小猫",
  "animations": {
    "idle": { "directory": "idle", "fps": 6, "loop": true },
    "drag": { "directory": "drag", "fps": 10, "loop": true },
    "mail": { "directory": "mail", "fps": 8, "loop": true }
  }
}
```

ZIP 可直接包含这些文件，也可以套一层文件夹；只能有一个 pet.json。directory 相对于 pet.json，帧文件放在该目录的直接下级，按文件名中的数字顺序播放，建议命名为 001.png、002.png。透明背景、统一画布尺寸的图片效果更稳定。

| 字段          | 要求                                   |
| ------------- | -------------------------------------- |
| schemaVersion | 固定为 1                               |
| name          | 1–60 字                                |
| idle          | 必需，至少一帧                         |
| drag / mail   | 可选，缺少配置或目录为空时使用 idle    |
| directory     | 包内相对目录，不允许绝对路径或上级路径 |
| fps           | 1–30，每秒帧数                         |
| loop          | true 循环；false 播放一次并停在末帧    |

支持静态 PNG、WebP，不支持 GIF、动画 WebP/APNG、SVG 或外部图片地址。单帧最大 512 × 512、2 MB；合计最多 240 帧、约 838 万像素。ZIP 最大 12 MB、256 个条目，解压后合计最大 16 MB。ZIP 不支持加密、分卷、ZIP64 或符号链接。

## 播放与交互

按住或拖动优先播放 drag；松手后有待处理收件则播放 mail，否则播放 idle。缺少某状态时使用 idle，一张图片也可使用。模板三个状态均循环播放。后台标签页暂停播放；系统启用“减少动态效果”时显示首帧。

拖动位置、点击打开收件箱、未读角标和收件轮询沿用原有交互。上传解压及图片解码在浏览器后台线程进行，有尺寸和时间限制；文件校验成功后才提供启用操作。
