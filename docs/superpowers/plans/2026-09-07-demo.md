# Context Hub Demo Implementation Plan

执行：本会话由主智能体逐项实施，用户明确禁止子智能体。

**Goal:** 可点击、可编辑、可回退并持久保存草稿的本地前端原型。
**Architecture:** React UI + 纯函数领域状态 + 浏览器本地存储；用例模拟网络服务。
**Tech Stack:** Vinext / React / TypeScript / Shadcn Base UI / CSS / Node test runner。
**Spec:** ../specs/2026-09-07-demo-design.md

## Global Constraints
- 仅本地 demo；保留根目录用户样本文件；禁止子智能体。
- 模拟能力在 UI 明示，不发起模型调用，不保存隐藏思考。
- 完整轮次是原文与压缩的最小单位；摘要覆盖和水位独立。

## Tasks
- [x] 1. `demo/lib/domain.ts` 定义工作区、轮次、摘要与召回行为。`demo/tests/domain.test.ts` 先检验 user/tool 归组、保留进度产生缺口、重置水位清除缺口、状态过滤及稳定 ID 覆盖。使用 `node --experimental-strip-types --test tests/domain.test.ts`。
- [x] 2. `demo/lib/seed.ts` 提供非敏感演示数据；`demo/app/page.tsx` 与 `demo/app/globals.css` 完成导航和原文时间轴首屏。启动 dev 并通过 HTTP 成功响应后打开预览。
- [x] 3. `demo/components/hub/` 拆分原文、摘要、Note、记忆包、收件箱与连接页面；`demo/lib/store.ts` 提供浏览器持久化及草稿。每种编辑器独立草稿 key，不以点击遮罩关闭。
- [x] 4. 摘要模拟任务采用检查点与显式开始/暂停；Note 有版本回退；插入轮次保持 ID 引用；所有外部连接明确演示不可用。
