# Context Hub 前端交互原型

阶段范围：仅本地、示例数据、浏览器持久化的前端 demo，不实现或假称已实现账号安全隔离、OAuth、MCP 服务、后台压缩或分享链接解析。不调用付费模型，不读取保存隐藏思考。用户要求本阶段先评审界面逻辑，禁止子智能体。

设计（按用户后续反馈修订）：纸张色手账书架为入口，工作区呈现为不同封面的对话册。点击封面进入册内，再以横向书签选择五个章节。取消固定系统式侧栏；翻开、切换章节与返回书架有连续过渡，并尊重减少动态效果的偏好。原文使用横向刻度时间轴、固定中心基准线与完整轮次详情；只渲染视窗附近的节点，支持键盘、滚动和轮次跳转。原文正文以预览、原始 Payload 和元数据分层呈现。

数据：工作区独立原文、摘要、Note、编排配置及演示连接。原文按 user 起始分组，assistant/tool 属于同一完整轮次。状态为正常/弃用/回收站；只召回正常内容。所有编辑有持久草稿且不因遮罩点击关闭。

摘要：独立记录覆盖的轮次 ID、处理水位和近期保留数量。两种回退分别重置水位或保留水位，未覆盖且已处理的轮次形成可见缺口。原文保留窗口跟随水位，批次模拟只推进完整轮次，30 条检查点上限，手动首次启动，可逐批审核、托管、暂停。提示词和记忆包均通过可重排块编排；活跃摘要块动态解析。

原型流程：样例分享链接进入收件箱；粘贴输入/输出、图片及附件形成完整轮次；收件箱重命名、按轮次删除、拼接或新工作区；Note 编辑、标星、历史恢复、弃用回收；记忆包重排、预览及复制；按工作区模拟令牌创建吊销、OAuth 授权页；模型配置不接收真实密钥，能力三态示意。

验证：对完整轮次、两个回退分支、缺口与召回过滤、插入后覆盖稳定性、检查点及重复推进边界进行行为测试。构建与类型检查；用户未要求浏览器自动测试，依技能只打开本地预览，不进行浏览器自动操作。移动端使用响应式导航和单列编辑。
