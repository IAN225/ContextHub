## 实现

- `demo/lib/hub-state.ts` 定义应用状态、工作区命令和收件命令。原文、摘要、Note、记忆包、连接页改发明确命令，在最新状态上只更新指定实体和字段，不再回传整份工作区。
- `demo/lib/use-hub.ts` 提供应用读取、即时操作和确认提交。`app/page.tsx` 保留导航、弹窗和通知；异步提交完成后，仅在原视图仍有效时执行跳转和关闭窗口。
- `demo/lib/repository.ts` 独立负责 IndexedDB，保留 `context-hub-demo` 数据库与 `data` 对象仓库。写入按调用顺序执行；多键写入共用一个事务；连接/事务失败不会阻断后续重试。
- `demo/lib/persistent-session.ts` 负责单一存储键的加载、修改、保存状态、确认提交和重试。`store.ts` 仅做 React 适配。旧请求不会更新另一个键的状态；旧保存完成事件不会把新修改标为已保存；读取失败时禁止用默认值写回。
- 新建手账、新建 Note、保存 Note 版本、保存完整轮次，将正式数据和草稿清理/更新放进同一事务。失败后保留原数据与草稿，编辑窗口继续提供提交入口；普通自动保存失败保留页面内修改并可重试。
- `hub-state-v1` 键保持不变，已保存内容增加 `schemaVersion: 1`。旧形状只补齐缺失的完成状态和收件来源，保留额外字段和自定义组件；未知版本或无法识别的根结构停止写入。草稿补齐新增默认字段，保留已有内容。
- `use-summary-task.ts` 管理模拟压缩：隐藏章节清理计时器，手动任务暂停；自动模式只在返回可见摘要页且条件满足时启动。连接页隐藏时停用时钟；通知计时器随状态变化或卸载清理。未完成的草稿保存仍落到原存储键。
