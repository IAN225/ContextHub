# 功能审查：源码目录与正式服务

审查日期：2026-09-13。

代码仍位于 demo/，这是历史目录名；源码和 Docker 部署运行同一份前端、Node 网关与 Workerd / D1 服务，没有另一套仅用于展示的产品页面。

| 范围 | 实际状态 |
| --- | --- |
| 原文导入、分享解析、API 投递、收件归档 | 已接入实际解析、下载与持久化；来源网站的权限和限流仍影响可用性 |
| Note、版本历史、摘要与记忆包 | 已接入真实业务处理，按云端账号保存 |
| 模型连接与后台摘要 | 已实现模型请求与后台队列；关闭网页不停止服务端已入队任务；没有代填模型凭据或伪造结果 |
| 附件、草稿、备份与回收站 | 已实现；云端业务数据不依赖浏览器存储；定期回收站清理在网页运行或再次打开时执行 |
| MCP / OAuth | 7 个真实 MCP 工具、令牌和授权均已实现，随账号保存 |
| 账号生命周期 | 此次增加随机管理员密码、强制改密激活、注册审批、关闭注册和角色管理 |
| 部署 | 此次提供源码安装脚本、Dockerfile、Compose、持久卷和初始化流程 |
| 实验性浏览器接口 | 已移除两个早期 WebMCP 演示接口；Claude / ChatGPT 使用的正式远程 MCP 不受影响 |
| 示例种子 | 已删除未使用的样例模块，首次加载从空手账开始 |

以下能力尚未实现，并非“demo 中有、正式服务没有”：向量语义搜索、OCR、PDF / Office 正文解析、音视频转写、邮件 / 系统推送、实时多人协作、完整富文本编辑、OIDC / CIMD。

目前的一致性限制：手账状态以账号内版本化 JSON 文档保存，不是实时协同。另一设备需刷新获取网页编辑结果；冲突会提示而不会静默覆盖。未下载的远端附件保存地址与状态，不能保证来源内容永远有效。

管理员在首页与手账页直接点击“管理员设置”，可管理注册审批、用户角色及 HTTPS 证书。前端拆分说明见 [模块地图](frontend-modules.md)，重装与账号数据恢复见 [完整备份指南](backup-and-restore.md)。

components/ui 还保留生成式 UI 模板，产品实际引用 dialog、button、tabs、select、checkbox、switch 六个组件。pnpm lint 检查产品页面、领域代码、脚本、测试及这六个基础组件；未使用模板存在既有静态规则问题，保留在库中，不计为已实现产品功能。TypeScript 仍检查整个源码目录。
