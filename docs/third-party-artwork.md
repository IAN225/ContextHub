# Conversation ornaments

## Clock-hand divider

`app/public/ornaments/clock-hand.svg` adapts the needle in [Compass by Lorc](https://github.com/game-icons/icons/blob/master/lorc/compass.svg), from game-icons/icons.

**Icons made by Lorc** ([author](http://lorcblog.blogspot.com)), licensed under [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/). See the upstream [license and attribution](https://github.com/game-icons/icons/blob/master/license.txt).

Changes: extracted the compass needle, rotated and cropped one half, reflected it vertically for a centered point, adjusted its proportions, and rendered it in a single color. CSS mirrors this half for paired left/right ornaments in button groups. The original compass circle is not included.

## Corners

`app/public/ornaments/clock-corner.svg` is original project artwork: two thin perpendicular lines, arrow tips and a small diamond. Only the bottom-left and top-right corners are shown. Its compact footprint leaves the user avatar and content at normal spacing.

Decorations are noninteractive and hidden from assistive technology. There is no separator below the user message. Tool calls and results appear in chronological order inside their assistant message group; source messages and attachment indexes are unchanged.


Turn dividers use an original miniature clock dial to the left of an italic serif round number, framed by <· and ·> marks. The dial is 17px and does not contain the number.
