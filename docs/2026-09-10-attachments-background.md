# 附件完整性与本地后台任务 · 2026-09-10

本轮接入附件字节保留、公开地址获取和持久化后台队列，沿用现有前端。用户已自行确认分享导入、手机体验和另一设备的模型正常返回；压缩质量尚未验收。

## 附件

- Chat Completions、Responses、Anthropic Messages 的图片/文件块和工具结果保留附件归属；分享解析保留公开地址和平台文件 ID。消息顺序不因附件改变，隐藏思考仍过滤。
- 内嵌文件与手动文件保存实际字节；公开 HTTPS 地址自动加入后台获取队列。状态明确区分已保存、待获取、来源缺失和获取失败。只有已保存文件提供下载；图片使用本地字节预览。失败可手动重试，不自动反复请求失效链接。
- 单文件上限 5 MB，记录字节大小与 SHA-256。来源只给私有 ID、登录页、失效地址或过大文件时保留引用及原因。请求投递整体仍有原来的 2 MB 上限，内嵌文件也计入其中。
- 下载只访问公开 HTTPS 标准端口，逐跳验证 DNS、固定已验证 IP，不携带 Cookie 或授权头；禁止内网、回环和保留地址。中断响应不会保存为完整文件。
- UTF-8 纯文本附件（txt/md/csv/tsv/json/log 等）在 128 KB 内提取正文，随元数据进入摘要与记忆包；图片、PDF、Office 等只保存文件，不做 OCR/文档解析，也不把二进制送给模型。未读取内容明确标记，避免模型误以为已看到文件。
- 下载完成时按附件 ID 和原引用核对，支持下载期间将收件归档。删除、回收站和替换的附件不会被旧结果复活；旧编辑草稿保存时会保留刚下载好的字节。已保存字节和状态随浏览器 JSON 备份往返。

## 后台执行和恢复

摘要压缩、工作台候选和附件获取写入本机 D1/SQLite 队列。`pnpm start` 和 `pnpm dev` 的启动器同时运行独立 Node 执行器，首页与手账顶部提供“后台任务”入口。

- 切换章节、关闭工作台、关闭网页后，已经入队的任务可继续运行；前提是启动服务的进程仍在且电脑未休眠。没有安装开机服务或云端执行器。
- 摘要以入队时的内容快照按批处理。开启逐批检查则每批后暂停；关闭后自动处理快照中的剩余范围。暂停会保留正在生成的本批结果，继续时核对原文/模型配置并采用当前逐批检查选项。新导入但尚未被浏览器接收的内容不属于已有快照。
- 队列一次领取一个批次，待处理任务和结果跨服务重启保留。排队任务继续执行；服务中断时正在调用模型的任务在 180 秒租约到期后转为暂停，需要检查后手动继续，避免不确定的请求自动重复计费。正常模型请求上限为两分钟。
- 每批结果先写入本机队列，再由页面接收。检查点、水位和接收凭证在 IndexedDB 同一事务保存成功后才确认并清理服务端结果。落盘失败可重试接收，无需再次调用模型；源内容变化时保留待处理摘要供复制，不覆盖新内容。
- 工作台结果进入候选列表，由用户确认应用。取消任务会丢弃未接收结果，已保存到手账的内容保留；停止摘要同时关闭该手账自动运行，避免取消后又自动入队。
- 模型 Key 从本机服务的私密配置读取（页面保存的连接优先，未设置时兼容环境文件）；任务保存连接指纹，连接改变时拒绝继续旧任务。执行器凭据由启动器临时生成，浏览器不接收该凭据。每个浏览器任务会话通过 HttpOnly Cookie 隔离；清理 Cookie 后无法接收原会话的未完成任务。
- 同一会话最多 20 个未结束或未接收任务。同一手账不能并发创建主摘要任务。完成且全部接收后清理任务正文与输入快照，保留状态和去重凭证。

## 启动与备份

```sh
cd demo
pnpm build
pnpm db:init
pnpm start
```

`start-demo.ps1` 也会执行构建和迁移；`0001_tasks.sql` 为新增任务表，保留原收件表。完整本地服务地址仍为 `http://127.0.0.1:3000`，持久化目录仍为 `demo/.wrangler/state`，不放进构建输出目录。开发启动也使用同一执行器；换环境首次开发前先按上面流程迁移数据库。

浏览器备份包含已经接收保存的结果和附件，不包含服务端未完成任务、未接收结果或密钥。恢复备份前会取消当前会话的后台任务与未接收结果，界面在覆盖确认处明确说明。回收站自动清理仍在页面打开时执行。
